# rifthead

Rift encode/decode helpers for head payloads in pipelines.

**Site:** https://theworker02.github.io/rifthead/

## Install / run

```bash
git clone https://github.com/theworker02/rifthead.git
cd rifthead
node src/cli.js
node --test
```
